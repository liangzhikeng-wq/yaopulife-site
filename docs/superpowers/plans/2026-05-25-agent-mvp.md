# Yaopulife Agent MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first local-file agent workflow for sourcing, image handoff, QC, readiness, profit, and purchase task creation.

**Architecture:** Add small CommonJS CLI modules under `scripts/` and store all generated operating data under `.agent/`. The first version stays isolated from live Astro pages and uses CSV/JSON instead of XLSX to avoid new dependencies.

**Tech Stack:** Astro project, Node.js CommonJS scripts, Node built-in `node:test`, CSV/JSON/Markdown files.

---
