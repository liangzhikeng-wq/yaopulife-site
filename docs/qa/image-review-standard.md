# yaopulife 生图审核标准 SOP

> 所有对外生图(文章插图 / 资料包封面+涂色页 / 视频卡 / Pinterest 图)在使用前必须过此审核。
> 数字员工生图必走;Claude 探路生图也走。**对外发布/上架前的最终拍板永远是用户(红线)。**
> 核心三原则:**① 跟文章典故匹配 ② 符合 yaopulife.com 品牌视觉配色 ③ 走规范审核流程,不达标返工。**

---

## 一、品牌视觉配色基准(硬约束,源自 yaopu.css :root)

| 角色 | 色值 | 用法 |
|---|---|---|
| 暖白宣纸底(主) | `#F4F1E8` / `#FCFAF4` | 背景主色,占比最大 |
| 墨(结构) | `#241E17` | 线条/文字/轮廓 |
| 朱砂(点睛) | `#A6362A` | 飘带/印章/重点,少量 |
| 暗金(点睛) | `#B0904D` | 冠饰/边框/器物,少量 |
| 玉绿(点睛) | `#2F6F5E` | 植物/灵气,少量 |
| 陶土(点睛) | `#BE5E38` | 辅助暖调,少量 |

**配色公式**:暖白底为主 + 墨线结构 + 矿物色(朱砂/暗金/玉绿/陶土)克制点睛。
**禁**:高饱和/霓虹/冷蓝白调/写实照片色/塑料感/3D 渲染感/纯黑底(涂色页必须纯白底)。
**prompt 引导词**:`warm ivory rice paper background, muted mineral colors, cinnabar and gold accents, traditional Chinese, no neon, no photorealistic`。

## 二、审核评分卡(出图后自检 → 对外前人审)

### 一票否决项(任一不过 = 返工,不入库)
1. **典故匹配**:主体 + 元素符合文章/资料的典故,文化准确。
   - 例:嫦娥 = 仙女 + 汉服 + 奔月/月 + 玉兔(+后羿/灵药背景);不得加错元素(龙/无关神兽)、错朝代服饰、错场景。
2. **主体辨识**:一眼认得出主体(先型后魂、具象、有脸有标志物)。看不出 = 废。
3. **合规**:公共领域典故 + 原创演绎(不抄他人作品/在世艺术家);无水印;无 AI 乱码文字;对外图标注 digital render。

### 打分项(每项 0–2,总分需 ≥ 4/6)
4. **视觉配色**:暖白中国风 + 矿物色点睛,协调 yaopulife.com。(0 跑调刺眼 / 1 可接受 / 2 协调统一)
5. **质量**:无崩手/崩脸/崩字,清晰,线条干净;涂色页 = 纯白底 + clean bold line。(0 崩坏 / 1 可用 / 2 精致)
6. **用途适配**:封面=具象优雅有冲击;涂色页=白底粗线稿;插图=匹配段落情绪。(0 不符 / 1 可 / 2 贴合)

**达标线**:3 个一票否决项全过 + 打分项总分 ≥ 4/6 → 入库。否则返工。

## 三、规范审核流程

```
1. 出图(ComfyUI / visualize / 合成)
2. 生产数字员工自检评分卡 → 记录每项分 + 典故ref + 用途
3. 不达标 → 返工(调prompt / 重出 / 后期校色到品牌色) → 重审
4. 达标 → 入库 assets/approved/ (附:典故ref、配色说明、用途、生成参数)
5. 对外用前 → 人审(红线:用户拍板,尤其上架/发布)
6. 用后 → 表现回流,优秀图沉淀进自有训练集(复利)
```

## 四、典故视觉要素清单(逐角色/主题建,审核"典故匹配"的依据)

> 每个角色/节日上线前先建此清单,生图按清单出、审核按清单核。

**嫦娥 Chang'e**:必含 仙女 + 汉服(襦裙/披帛) + 满月 + 玉兔(可选) + 奔月动势;可选 灵药/桂树/后羿弓影;禁 现代服/错朝代/非月场景/龙。
**玉兔 Jade Rabbit**:兔 + 捣药杵臼 + 月/桂树;萌系可爱(面向K-5);禁 写实兔/凶相。
**(后续角色)**:孙悟空/哪吒/后羿/女娲/十二生肖/各节日 — 逐个补清单,存入视觉圣经 docs/visual-bible/。

## 五、各用途出图规格
- **资料包封面**:具象主角(工笔/水墨)+ 暖白排版框 + 中英标题 + 品牌色 + 蒲印。
- **涂色页**:纯白底 + 粗黑 clean line,无灰阶无填充,主体可爱(K-5)。
- **文章插图**:匹配段落典故/情绪,暖白中国风,可工笔可水墨。
- **视频卡/Pinterest**:9:16 或竖图,主体居中,品牌色,蒲印片头。
