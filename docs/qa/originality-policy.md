# 原创性政策 · Originality Policy

> 原创不是乱画。**原创 = 文化理解 + 结构锚点 + 自有视觉语言。**

## 硬规则
1. 不得直接模仿任何小红书博主、画家、插画师、影视、动漫、游戏作品。
2. 只允许借鉴**抽象方法**：留白、线稿、色彩克制、文化符号组织方式、构图法则（如一角半边）。
3. 所有角色造型只能来自三个来源：
   - 中国神话**文本理解**（story bible）
   - yaopulife **视觉圣经**（visual bible 的 shape/spirit anchors）
   - 自有 **approved assets**（资产库已通过审核的资产）
4. **不得使用 "in the style of <在世/具名艺术家>"**（如韩美林）—— 版权 + 风格挪用红线。
   - 公共领域（作者逝世满 50 年，如齐白石 1957 卒）可作**抽象方法**参考，仍不得复制具体作品/构图。
5. 不得复制现有构图。
6. 不得让人物像某个影视版本；不得让神兽像某个游戏怪物。
7. 训练用数据**只用公共领域 / 自有授权**素材（古画白描等），来源登记在 LoRA 的训练记录里。

## 与生图引擎的关系
- prompt **禁止**出现具名在世艺术家的 "in the style of"。
- 允许的风格描述是**画法本身**（gongbi baimiao / ink wash / 留白 / 朱砂画眼），不是"某人画的"。
- 专属 LoRA 必须基于合法数据训练，否则视为违规资产，不得入库。

## 审核挂钩
- 质检（`visual-quality-check.md`）含"原创性"项；原创性不足 → 重做设计方向，不得入库。
