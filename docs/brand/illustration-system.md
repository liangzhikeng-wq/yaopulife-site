# yaopulife 插画系统规范 · Illustration System

## 1. 插画定位
yaopulife 插画是:**New Chinese healing narrative illustration for global readers.**
新中式治愈萌趣叙事插画 —— 用现代、干净、温暖的方式讲中国神话、生肖、节日与文化故事。

**最终融合画法**:东方留白 + 萌趣角色 + 水墨笔触 + 文化符号 + 情绪叙事 + 海外可理解。

关键词:authentic · poetic · warm · clean · story-driven · gentle · mystical · globally approachable · paper texture · ink line · cinnabar accent · restrained Chinese symbols。
**不要**:过度国潮 / 红金堆砌 / 低幼儿童插画 / 廉价 AI 海报 / 复杂游戏原画 / 赛博中国风 / 纯扁平互联网插画。

## 2. 插画原则(每张必满足)
- Clear subject(一眼看懂主题)
- One clear emotion(一秒感到情绪)
- One cultural symbol(≥1 个东方文化符号)
- Large negative space(留白足够)
- Restrained palette(颜色克制)
- Hand-drawn ink feeling(手绘水墨感)
- Globally understandable(海外可理解)
- Series-ready(可作系列资产延展)
- 不直接模仿任何博主

## 3. 构图模板
- **A. Central Character** — 主体居中偏下,适合生肖、动物、IP 角色。
- **B. Moon Gate / Circle Frame** — 圆窗、月洞、团扇构图,适合神话、节日、禅意图。
- **C. One-line Small World** — 一条横线构成小世界,适合系列小图、知识卡。
- **D. Ink Animal Persona** — 动物占画面 50%–60%,人格化、情绪化,适合生肖和神兽。
- **E. Editorial Story Cover** — 人物/符号/标题共同构成叙事,适合文章封面。

## 4. 线条规范
Deep Ink 作主线;外轮廓稍粗、内部细节较细;手绘感;允许轻微断笔、飞白;**避免机械矢量感**。

## 5. 色彩规范(每张最多 4 主色)
- 背景:Paper / Warm Paper
- 线条:Ink / Deep Ink
- 主强调:Cinnabar
- 次强调(三选一):Jade / Bamboo Green / Moon Gold

> 品牌色板见 `src/styles/tokens.css`(`--color-*`)与 `docs/brand/brand-visual-upgrade-summary.md`。

## 6. 文化符号库(每张最多 1–3 个,服务叙事不堆砌)
red sun · moon · bamboo leaves · distant mountains · cloud pattern · lantern · moon gate · paper texture · seal stamp · pine branch · lotus leaf · water ripple · tiled roof · small boat · plum branch · tea cup · scroll · fan。

## 7. 三类小红书画法(抽象方法,不模仿具体博主)
1. **治愈萌物简笔画**:圆形主体 + 黑色柔线 + 小情绪 + 小动作 + 小道具 + 大留白。用于生肖/动物 IP/治愈卡/社媒封面。
2. **国风禅意极简**:大留白(60–75%) + 少元素 + 东方符号 + 朱砂点睛 + 诗意构图。用于神话封面/节气/节日/网站 hero。
3. **水墨萌趣动物人格化**:水墨骨架 + 萌趣比例 + 人格动作 + 情绪表情 + 东方点缀。用于 12 生肖/神兽/山海经动物/吉祥物。

## 8. 输出尺寸
1:1(通用) · 4:5(社媒/Pinterest 竖) · 3:4(卡片) · 16:9(网站 hero) · 9:16(Shorts/竖屏封面)。
