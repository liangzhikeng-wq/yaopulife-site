# 耀蒲视觉·灵魂法则 v1（中国风极简手绘插画）

> 沉淀自绘画理论（谢赫六法 / 留白意境 / 丰子恺诗意 / 治愈系叙事）。
> 一句话标准：**画要"活"（气韵生动）、要有"画外之意"（弦外之音）、要能共鸣（情绪叙事）——不是把元素摆整齐的装饰图标。**

## 七条可执行法则

1. **经营位置（构图造势）**：拒绝居中对称。用"一角半边"（马远式），主体偏置一侧，对角线造"势"，疏密强对比；空与物"揖让穿插、若即若离"。
2. **计白当黑（留白即气）**：画面 60–75% 是空。留白不是没画，是天/水/雾/气，是观者再想象的余地。空，才有气韵。
3. **骨法用笔（线有筋骨）**：每根线有起笔—行笔—收笔、提按顿挫；有粗细变化、有飞白枯笔。绝不匀速等宽几何线。
4. **墨分五色（焦浓重淡清）**：墨要分 3–5 个层次（近浓远淡、主浓次淡），加一点墨韵晕染（湿边）。不用一个纯黑平涂。
5. **画眼（一点经营）**：全画引向一个焦点——通常是"万绿丛中一点红"（那一抹朱砂：日/灯/果/印），或唯一的活物（鸟的回眸）。其余皆为它让路。
6. **弦外之音（小中见大）**：少画、多留。寥寥数笔勾无限意境；画一个瞬间，让人感到它的前后；触动一种普遍心境（孤寂/归意/温情/旷远）。
7. **诗书画印（题款入境）**：题字不是贴标签，是入画——落在留白边缘与画呼应，添"余音"；朱印是构图的平衡砝码与第二画眼。

## 情绪先行（治愈系的命门）
先定**一种心境**（黄昏归意 / 团圆思念 / 旷远孤寂 / 萧瑟生机 / 闲适安宁），再让构图、墨色、留白、那一点红都为这个情绪服务。**情绪 > 元素**。日常细节承载情感引发共鸣（代入感）。定位取**宋画意境**（简约清雅、以意境取胜），非唐风浓艳。

## SVG 落地技法（怎么在矢量里逼近笔墨）
- **锥形笔触**：用 filled path 做"起粗收尖"的笔形，替代等宽 stroke。
- **墨分五色**：3–4 个墨阶（#1A140E 焦 / #3A2E22 浓 / #5C4E3E 淡 / #8A7A66 清干），近浓远淡。
- **墨韵湿边**：深线下叠一层 feGaussianBlur 低透明深色，模拟墨入纸的洇。
- **飞白枯笔**：主笔上叠几条断续细浅条（纸色或清墨），做出枯笔擦痕。
- **宣纸肌理**：feTurbulence 颗粒底；轻 displacement 让线缘自然抖动。
- **一点朱砂**：朱砂（#A6362A / 陶土 #BE5E38）只给画眼用，且略带两阶不纯平，更像颜料。

## 验收（怎样算"有灵魂"）
- [ ] 不居中、有势、疏密分明、有明确画眼
- [ ] 留白 ≥60%，且留白"有内容"（是天/水/气）
- [ ] 线有粗细飞白节奏；墨有 ≥3 阶
- [ ] 一眼能感到一种**情绪/心境**，有余味想多看
- [ ] 题款入境、朱印平衡——不是机械贴角
- 不达标返工，别上线。

### 灵魂 = 五件事（不是风格，是这个）
1. **主角是"谁"，有脸、有表情、有性格、有情绪**——三家都在画角色，不画空景。胖虎"外强中干"、熊猫"害羞"，**情绪/性格才是魂**。
2. **萌（憨圆拙）**——讨喜的笨拙感（胖/圆/呆/大眼）＝亲切。
3. **真笔墨手感**——墨分浓淡、飞白、湿晕、纸纹；**手感的"不完美"才有命**，矢量的"准与匀"＝机械＝死。
4. **一个瞬间＋一句人话文案**——把画变成会说话的朋友。
5. **一点暖色画眼**——那颗橙日／那颗爱心。

### 我之前为什么没灵魂（定论）
- 画的是**冷空景**（孤舟/寒枝），没有可爱的**角色**——再美也没人疼、是死的。
- 用**矢量钢笔尖**模拟**湿毛笔**——方向性错误，到顶了。博主3 自己标注"AI辅助"=真水墨墨韵来自扩散模型/真笔，SVG 凿不出。

### 落地转向（对我们神话内容是绝配）
我们满是角色：悟空/哪吒/龙/玉兔/年兽/十二生肖/白蛇。**把神话角色画成"水墨萌趣"**（悟空＝虚张声势的萌猴、年兽＝又凶又怂的胖兽、玉兔＝困困捣药…），有脸有情绪有幽默＋一句英文人话＝灵魂＋贴内容＋接耀蒲娃IP＋海外社媒爆款相。
**工具：本地 ComfyUI（水墨写意＋萌系角色）＋蒲印/题字后期。SVG 退居图鉴线/排版，不再用于神话主视觉。**

## 最终定论（2026-06-27 晚·用户拍板 A，前述 ComfyUI 萌系/水墨方向均作废为「站主视觉」）

反复卡的**根**＝画与站不是一套视觉语言：站＝**扁平·编辑设计**（CSS：暖纸／衬线／巨幕淡汉字／细红线／玉绿卡／蒲印），我却一直在出**水墨绘画**＝另一套语言，再好也像"贴进来的"。

**选 A：图进站的扁平编辑体系**
- 扁平 **SVG 图形** ＋ 站**精确色板**（`--paper/--ink/--clay/--cinnabar/--gold/--jade`）＋ 视觉锤（蒲印／巨幕汉字／红线）＋ 衬线。
- **魂靠立意＋构图＋留白＋一点朱砂画眼**（非笔触；小Q简笔证明扁平能有魂）。
- 每角色＝**立意驱动的扁平 hero 插画内联进 `.story-hero.illus`**（SVG 用 `fill="var(--xxx)"` 拿精确品牌色 → 与 CSS 站天然同体系）。
- ComfyUI 水墨/萌系 → 留作社媒/其他，**不做站主视觉**。6 篇暗黑奇幻文案**不动**。
